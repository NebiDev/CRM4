# NEXA

Multi-tenant CRM and marketing platform for a freelance/agency business.
Manage clients, projects, tasks, agreements, invoices, files, and team access —
plus a public marketing site selling digital infrastructure, automation,
payroll systems, and custom internal tools.

## Stack (pinned)

- Node.js 22.14, TypeScript 5.4
- Express 4 + Zod
- Prisma 5.22 + PostgreSQL (Neon)
- Better Auth 1.2.7 (email/password + organizations)
- React 18 + Vite 5 + Tailwind 3.4
- TanStack Query 5, React Hook Form 7, TanStack Table 8
- AWS S3 (private, presigned URLs)
- Resend (transactional email)
